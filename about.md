I'm a software developer from Budapest, Hungary.
I started my software career as a web application developer but my interests
gradually shifted towards other domains of the computing world,
mostly the lower layers - operating systems, networks, things close to the hardware.
I began as a self-taught developer but eventually acquired a Bsc in
computer science & software engineering.

I spent the first 5 years of my software career with the good old LAMP stack.
Then in 2018 I switched to cloud infrastructure / devops (AWS, then Azure)
and did that until 2025.

I've been working on a side project since 2019 - a [PACS][pacs] and medical image sharing
application stack for health care providers.
At the core of it are the open source [Orthanc DICOM server][orthanc], the [OHIF image viewer][ohif],
a custom DICOM worklist server and mediator ([golang][golang])
and a minimal worklist management UI (proudly written in [Elm][elm]).

In 2025 this side project became my full-time job - today I'm working on the various components,
manage the builds and deployment automation and often troubleshoot on our on-prem linux hosts.
